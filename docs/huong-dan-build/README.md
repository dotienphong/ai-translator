# Hướng dẫn build AI Translator

| Hướng dẫn | Nội dung |
|---|---|
| [`build-dmg-macos.md`](build-dmg-macos.md) | Build tay file `.dmg` cho macOS (ký ad-hoc, chưa notarize) để đưa người dùng tải về cài |

Các tài liệu liên quan:
- Quy trình phát hành chính thức qua CI (ký bản cập nhật, đăng `latest.json`, khóa, tên miền): `docs/release/phat-hanh.md`.
- Bản macOS ký ad-hoc và những gì đã đo: `docs/superpowers/specs/2026-10-05-macos-adhoc-signing-design.md`, `bench/phase1/results/gd1_adhoc_keychain.md`.
- Văn bản pháp lý (EULA, chính sách quyền riêng tư) đóng gói trong app: `docs/legal/`.

Hướng dẫn build cho Windows chưa có (làm ở đợt Windows).
