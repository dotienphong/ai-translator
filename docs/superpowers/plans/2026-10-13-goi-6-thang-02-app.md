# Gói 6 Months · Kế hoạch 02: app

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** app nhận token, bán và hiển thị gói `six_months` (6 Months); màn hình Nâng cấp hiện bốn thẻ đồng bộ với kiểu hiện có; luồng mua, kích hoạt, hạn mức và mọi tính năng khác không đổi.

**Architecture:** hạn mức của app đọc từ token và bảng gói đọc từ server, nên chỉ cần: biến thể `Plan::SixMonths` (Rust), mã gói trong danh sách bán được và khai báo `?plans=` với server (để máy cũ không thấy gói mới, spec §2.3), mã gói và chuỗi giao diện (5 ngôn ngữ), dữ liệu giả của trang xem trước, và một sửa CSS để bốn thẻ xếp 2×2. Vector token dùng chung với server được thêm cùng commit với enum Rust.

**Tech Stack:** Rust (Tauri 2, reqwest blocking, serde, rustfmt, clippy), React 19 + zustand, TypeScript, Vitest (môi trường Node), Vite, trang xem trước `scripts/ui-preview` + Google Chrome không đầu qua CDP.

**Spec:** `docs/superpowers/specs/2026-10-13-six-months-plan-design.md` (§1, §2.3, §3). Điều kiện: kế hoạch 01 (server) đã xong Task 1 đến 4 (cần `PLAN_CODES` có `six_months` để test server nhận vector mới; server đang có 678 test).
